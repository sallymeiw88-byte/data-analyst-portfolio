# ⚖️ Legal Claims Analysis with Python

## 📌 Project Overview

This project analyzes a fictional legal claims dataset using Python and Pandas.

The goal is to explore case status, damage types, insurance companies, estimated damages, settlement amounts, and case duration to identify simple business insights that could support legal case management and reporting.

## 🛠️ Tools & Technologies

* Python
* Pandas
* Google Colab
* Matplotlib

## 📊 Business Questions

* How many cases are open vs. closed?
* What damage type is most common?
* Which insurance company has the most cases?
* What is the average estimated damage?
* What is the average settlement amount for closed cases?
* How long does it take to close a case on average?
* Which damage types have the highest average estimated damage?

## 🔎 Key Findings

* There are **201 closed cases** and **99 open cases**.
* **Fire** is the most common damage type, with 67 cases.
* **Heritage** has the highest number of cases, with 56.
* The average estimated damage is **$26,871.42**.
* The average settlement amount for closed cases is **$25,638.21**.
* The average case duration for closed cases is approximately **92.79 days**.
* **Roof** has the highest average estimated damage at approximately **$29,110.82**.
* **Water** has the lowest average estimated damage at approximately **$24,584.61**.

## 📈 Visualizations

The project includes visualizations showing:

## 📁 Files

## 💡 Conclusion

The analysis shows that case frequency and financial impact can vary by damage type. Fire cases are the most frequent, while Roof cases have the highest average estimated damage.

The project demonstrates basic data cleaning, exploratory data analysis, grouping, filtering, date calculations, and data visualization using Python and Pandas.

> **Note:** This project uses fictional data created for portfolio and learning purposes. No real client or case information is included.
